# File Organizer Pro

A simple yet powerful desktop automation tool built with Python that automatically organizes messy folders into structured categories.

---

## 🚀 Features

- One-click folder selection
- Automatically sorts files into categories:
  - Images 🖼️
  - Videos 🎥
  - Documents 📄
  - Audio 🎵
  - Others 📁
- Creates folders automatically if they don’t exist
- Moves files safely without deleting anything
- Clean and simple GUI interface

---

## 🧠 How It Works

The tool scans all files in a selected folder, checks their file extensions, and moves them into appropriate directories for better organization.

---

## 🛠️ Technologies Used

- Python
- Tkinter (GUI)
- OS module
- shutil module
